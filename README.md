## 📖 About This Repo

I'm a computer science student building my way toward Web Application Penetration Testing, and eventually AI Red Teaming. Linux and networking gave me the ground to stand on — this repo is where I learned to move on it.

Every script here solves a problem I understood well enough to build a solution for, not one I copied from a tutorial. If a tool is rough around the edges, it's because I wrote it myself — not because I found it somewhere.

- The concepts, explained in my own words
- The tools, built from scratch, not templated
- The bugs I actually hit, and how I actually fixed them
- No tool ships until it handles bad input without crashing

Nothing here is copy-pasted from a tutorial. If something is wrong, it's because I understood it wrong — not because I copied it wrong.

## ⚙️ Tooling Standards & Architecture

- **CLI-first:** Every tool takes its input through command-line arguments (`argparse` / `sys.argv`), with no hardcoded targets.
- **Fail-safe:** Every tool handles errors and bad input with `try/except`, so it never crashes on unexpected data.
- **Documented:** Every tool ships with a full README: usage, examples, and the bugs I hit while building it.
